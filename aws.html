Amazon Web Services (AWS)

Amazon Web Services — это признанный лидер мирового рынка облачных вычислений. Платформа предоставляет масштабную и надежную экосистему, включающую более 200 полнофункциональных сервисов, развернутых в десятках географических регионов по всему миру.

Фундаментальные компоненты AWS

Инфраструктура Amazon построена таким образом, чтобы компании любого масштаба могли разворачивать отказоустойчивые системы без необходимости закупки дорогостоящего аппаратного обеспечения.

  • Amazon EC2 (Elastic Compute Cloud): Сервис виртуальных серверов с возможностью динамического изменения конфигураций и автомасштабирования под нагрузкой.
  • Amazon S3 (Simple Storage Service): Высоконадежное объектное хранилище для статических файлов, бэкапов и медиаданных с показателем долговечности 99.999999999%.
  • Amazon RDS (Relational Database Service): Управляемые облачные базы данных с автоматическим резервным копированием и репликацией.
  • AWS Lambda: Бессерверные вычисления (Serverless), выполняющие код в ответ на события без администрирования серверов.

Преимущества и масштабируемость

Главным достоинством AWS является гибкая модель оплаты Pay-as-you-go (оплата только за фактически потребленные ресурсы), а также развитая сеть доставки контента (CloudFront) и инструменты глубокого мониторинга (CloudWatch).

Масштаб

AWS обслуживает миллионы активных корпоративных клиентов по всему земному шару.
