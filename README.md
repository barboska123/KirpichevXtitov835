# Учебный проект: «Облачные технологии и VPS»

Многостраничный информационный ресурс, посвященный выбору VPS, облачным платформам (AWS, GCP), контейнеризации (Docker, Kubernetes), безопасности и оптимизации затрат (FinOps).

## Автор
* **Титов Дмитрий Николаевич**

## Структура проекта
* `index.html` — Главная страница руководства.
* `vps-what-is.html` — Что такое VPS/VDS.
* `aws.html` — Обзор Amazon Web Services.
* `gcp.html` — Обзор Google Cloud Platform.
* `comparison.html` — Сравнительная таблица облачных провайдеров.
* `security.html` — Безопасность и брандмауэры.
* `containers.html` — Контейнеризация (Docker и Kubernetes).
* `finops.html` — Ценообразование и FinOps.
* `deployment.html` — Практическое руководство по деплою (с видеоинструкцией).
* `conclusion.html` — Заключение.

## Технологии
* HTML5 / CSS3
* Tailwind CSS (через CDN)
* Адаптивная верстка (Mobile-First)
